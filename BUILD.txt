Bud&Leaf Teams v7a - identity checkpoint

Base:
- v6b stable recovery build
- rollback branch: v6b-stable-checkpoint

This checkpoint adds the Teams v1.1 identity/provenance layer without cloud sync.

PROJECT IDENTITY
- schema_version: 1.1
- project_uuid: permanent cross-device project identity

FEATURE IDENTITY
- tree_id remains the clean visible field ID: T1, T2, G1, etc.
- capture_id preserves the field ID assigned at capture
- final_id is reserved for later final renumbering
- feature_uuid is the permanent hidden identity
- surveyor_code is separate, e.g. JR / EH
- surveyor_name is retained
- created_at / updated_at are retained

MULTI-SURVEYOR NUMBERING
- each registered surveyor has their own T/G/H/W field sequence
- JR can have T1 while EH can also have T1
- another surveyor's records do not advance your sequence
- legacy unassigned records still act as the common baseline

GROUP STEMS
- parent_id remains for compatibility
- parent_feature_uuid is added so duplicate visible group IDs across surveyors do not collide

UI / EXPORT
- Current project shows Surveyor: JR
- normal survey CSV contains a separate Surveyor column
- full-field CSV and GeoJSON retain identity/provenance fields
- project packages carry project_uuid and schema_version

MIGRATION
- existing projects are upgraded additively on open
- existing features receive UUID/capture/final/timestamp fields if missing
- existing visible IDs and survey data are preserved

NOT ADDED YET
- merge engine
- conflict detection
- Firebase/cloud sync
- photo sync
- final spatial renumbering
