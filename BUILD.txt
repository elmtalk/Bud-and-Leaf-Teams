Bud&Leaf Teams - surveyor registration checkpoint
Base: recovery v5 / R2D2 stability build
PWA cache: bud-leaf-teams-v6-surveyor-registration

This build adds ONE Teams feature only:
- asks for surveyor name + 2-3 letter code before opening the field map
- stores the surveyor registry in project_meta.teams_surveyors
- remembers this device's surveyor for that project
- rejects a code already assigned to another named surveyor in that project
- persists the registry through the normal Bud&Leaf save path

Not changed:

- project opening/import logic
- map logic
- feature IDs
- UUIDs
- exports
- cloud/Firebase
- page layout/CSS
